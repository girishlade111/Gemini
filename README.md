# Gemini

A small experimental playground built around Google's **Gemini API** — exploring prompt engineering, generative-AI responses, and basic integration patterns with the Gemini model family.

> **Note:** This repository currently contains no working demo code — it is a stub that reserves the project name. The reference implementation that once used a hardcoded Gemini API key has been removed; API keys should never be committed to git history (rotation is handled separately).

## Features

- Playground for testing prompts against Google Gemini models
- Experiment scaffolding for generative-AI integrations

## Tech stack

- Google Gemini API (generativelanguage.googleapis.com)
- JavaScript / Node.js (planned)

## Quick start

```bash
git clone https://github.com/girishlade111/Gemini.git
cd Gemini
# Add your own integration here — keep API keys in environment variables
```

> Never commit API keys. Use environment variables (e.g. `GEMINI_API_KEY`) or a secret manager instead.

## Security note

If you previously pushed an API key to this repo, **revoke/rotate it in Google AI Studio** — rewriting or deleting files does not erase it from git history.
